# 카드 문자 자동 입력 목 기능

카드 승인 문자를 붙여넣으면 거래 내용을 추출하고 카테고리를 추천하는 UI 체험이다. 실제 AI 호출 없이 규칙으로 처리하며 사용자가 확인한 뒤에만 브라우저에 거래를 저장한다.

## 추가 요구사항 원문

```text
여기에 할 것은 카드 메시지를 붙여넣기를 하면, 내용이 자동적으로 골라지고, 이걸 ai를 통해서 하는 방식으로 가보자. 다만, 아직 ai를 적용할 것은 아니고, ui를 통해서 적용하는 모습만 보여주는 목으로 만들 거야.
```

## 구현 계획과 사용 흐름

1. 국내 원화 승인 문자 한 건에서 날짜·금액·사용처를 추출한다.
2. 사용처 키워드로 카테고리를 추천하며 모르는 사용처는 직접 선택하도록 둔다.
3. 기존 거래 폼에 추출값을 채우고 모든 필드를 수정할 수 있게 한다.
4. 사용자가 저장 버튼을 눌렀을 때만 브라우저 저장소에 반영한다.
5. 추출·거절 규칙과 화면 동작을 확인하고 테스트·빌드·정적 검사를 실행한다. 사용자의 최신 지시에 따라 검증한 작업을 커밋한다.

입력 도우미의 **카드 문자 붙여넣기**를 누르거나 거래 추가 폼의 **카드 문자로 자동 입력**을 펼친다. 문자를 넣으면 필드가 자동으로 채워지고 추천 이유가 표시된다. **예시 체험**으로 합성 문자를 넣을 수도 있다. 카테고리는 추천 뒤에도 드롭다운에서 직접 선택한다.

## 예시와 검증

```text
[Web발신]
모아카드 승인
5,500원 일시불
2026/10/13 14:30
달빛커피
누적 125,500원
```

추출 결과는 날짜 `2026-10-13`, 지출 `5,500원`, 사용처 `달빛커피`, 카테고리 `카페`다. 누적 이용 금액은 이번 거래 금액으로 사용하지 않는다. 연도가 없으면 현재 연도를 기준으로 하며 1월에 붙여넣은 12월 문자는 전년도 날짜로 보정한다.

해외 통화, 취소·거절, 여러 거래, 날짜·금액·사용처를 찾을 수 없는 문자는 안내하고 저장을 막는다. **직접 입력으로 계속**을 누르면 문자 입력을 비우고 폼에서 직접 입력할 수 있다. 알 수 없는 카테고리는 필수 선택 검증으로 저장을 막는다.

## 현재 범위

카드사별 모든 형식, 해외 결제, 취소 거래, 이미지·영수증 인식과 중복 문자 판별은 지원하지 않는다. 목 기능은 거래 한 건의 입력 흐름에 집중한다. 외부 AI나 서버에 문자 원문을 보내지 않고 원문을 거래 메모로 저장하지 않는다.

실제 AI 도입 시 추출 구현을 인프라 경계에서 교체하고 [RAG 카테고리 추천](category-rag.md)을 연결한다. 사용자 수정·확인과 금액 검증은 유지한다.
