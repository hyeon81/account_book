# AI 채팅을 통한 가계부 통계 조회

“저번 주에 내가 간 카페 횟수” 같은 질문을 기간·필터·지표로 변환하고 서버가 계산한 값을 설명한다. 이번 설계의 알림은 요청한 채팅에 결과를 보여주는 동작이다. 정기 실행과 이메일·푸시 발송은 후속 기능이다.

## 기간과 횟수의 정의

서버가 전달한 Asia/Seoul 기준 시각으로 상대 기간을 계산한다. “저번 주”는 지난 월요일부터 이번 월요일 직전까지다. 서버 내부는 시작 포함·종료 제외 날짜를 사용한다. 기준 시각이 `2026-10-06T12:00:00+09:00`이면 `2026-09-28` 이상 `2026-10-05` 미만이다.

현재 거래에는 방문 ID나 시각이 없어 카페 결제 건수만 셀 수 있다. 하루의 두 결제가 같은 방문인지 구분할 수 없으므로 “기록된 카페 지출 3건”이라고 표시한다. 실제 방문 횟수에는 추가 데이터 모델이 필요하다. 사용처·날짜만으로 방문을 임의 합치지 않는다.

## 에이전트와 집계 도구

1. 질문에서 상대 기간, 카테고리, 거래 유형과 지표를 추출한다.
2. `resolve_period`가 서버 기준 시각으로 날짜 경계를 확정한다.
3. `aggregate_transactions`가 검증된 기간과 카테고리의 확정 거래를 집계한다.
4. 에이전트가 서버 결과를 설명하고 기간·필터·단위를 표시한다.
5. 서버가 설명의 수치를 검사한다. 모델이 건수를 다시 세거나 거래 목록을 받아 합산하지 않는다.

도구 인자는 `metric`을 `count` 또는 `sum`, `type`을 `income` 또는 `expense`로 제한한다. `group_by`는 없거나 `category` 또는 `date`다. 최대 조회 기간 366일과 최대 그룹 수 366개를 실습 정책으로 제안한다. 사용자 ID는 인자에 포함하지 않고 서버 문맥에서 결정한다.

## 도구 요청과 결과 예시

다음은 내부 도구 인자 제안이다. `cafe`는 현재 UI와 일치하며 서버가 허용 여부를 다시 검증한다.

```json
{
  "period_start": "2026-09-28",
  "period_end_exclusive": "2026-10-05",
  "type": "expense",
  "category_id": "cafe",
  "metric": "count",
  "group_by": null
}
```

합성 자료에 9월 28일 카페 1건, 10월 2일 카페 2건, 10월 5일 카페 1건이 있다면 앞의 3건만 포함한다. 미확정 초안·다른 카테고리·수입은 제외한다.

```json
{
  "period_start": "2026-09-28",
  "period_end_exclusive": "2026-10-05",
  "type": "expense",
  "category_id": "cafe",
  "metric": "count",
  "value": 3,
  "unit": "transaction",
  "basis": "confirmed_transactions"
}
```

답변은 “9월 28일부터 10월 4일까지 기록된 카페 지출은 3건입니다. 결제 건수 기준이며 실제 방문 횟수와 다를 수 있습니다.”처럼 표현한다. 내부 종료 제외 날짜는 화면에서 마지막 포함 날짜로 바꾼다. 기존 API 계약의 `period_end`는 포함 날짜이므로 내부 필드를 그대로 치환하지 않는다.

## 모호한 질문과 오류

“요즘 카페 많이 갔어?”는 기간과 비교 기준이 없어 먼저 묻는다. “지난 7일”과 “저번 주”를 동일하게 처리하지 않는다. 질문에 없는 카테고리나 통계를 임의 추가하지 않는다.

정상 조회에 기록이 없으면 `value: 0`과 적용 범위를 반환한다. DB·도구 오류를 0건으로 표시하지 않는다. 모델 거절·타임아웃은 오류로 처리하고 일반 통계 화면은 유지한다. 예약·외부 발송 도구는 초기 목록에 없다.

## 교육 실습과 완료 기준

시간을 고정해 일요일·월요일, 월말·연말의 경계, 시작일 포함·종료일 제외를 시험한다. 같은 날 여러 거래, 빈 기간, 잘못된 카테고리, 미확정 초안과 사용자 범위도 검증한다.

모델 대역이 건수를 바꾸면 서버가 차단하는 테스트를 추가한다. 임의 SQL·쓰기 도구 호출이 거절되고 채팅에 기간·필터·단위가 표시되면 완료다. 도구 흐름은 [공통 에이전트 구조](agent-architecture.md)를 따른다.
