# 웹 UI의 AI 태그와 AI 위키

docs/ai의 설계를 브라우저에서 설명하는 위키다. 실행 가능한 AI 서버를 추가하는 작업이 아니다.

## 화면 위치와 동작

- 상단 오른쪽 끝의 AI 위키를 누르면 개요가 열린다.
- 입력 도우미 메뉴에 AI 태그를 표시하고 제목에는 AI 미리보기를 표시한다.
- 입력 도우미의 카테고리 추천·채팅 통계 AI 설계 태그는 해당 위키 절을 연다.
- 대시보드의 규칙 통계·주간 비교 태그는 해당 에이전트 설계 절을 연다.
- 일반 월별 집계·거래 저장을 AI 계산으로 표시하지 않는다.
- 위키에서 입력 도우미로 돌아갈 수 있고 거래·대화의 화면 상태는 유지한다.

## 문서 구성과 현재 상태

개요는 UI 영역과 AI 기능·에이전트 흐름을 표로 연결한다.
카테고리 추천은 RAG, 채팅 통계는 해석→기간 확정→서버 집계,
규칙 통계는 선택→검증→평가, 주간 비교는 Plan-and-Execute를 설명한다.
공통 도구와 MCP 절은 계산·권한·외부 접근의 경계를 설명한다.

현재 입력 도우미는 키워드 기반 각본형 미리보기다.
RAG 검색·실제 LLM·AI 규칙 평가·계획 실행·MCP 연결은 후속 설계이며
작동 중인 기능처럼 표시하지 않는다. 거래는 브라우저 localStorage에 저장한다.

출처는 [AI 설계 색인](../docs/ai/README.md)과 각 기능 문서다.
위키의 출처 파일명은 설명이며 브라우저에서 제공되지 않는 Markdown URL을 링크하지 않는다.

## 주소와 접근성

주소 예시는 `#ai-wiki/overview`, `#ai-wiki/category-rag`,
`#ai-wiki/chat-statistics`, `#ai-wiki/rule-statistics`,
`#ai-wiki/plan-and-execute`, `#ai-wiki/tools`, `#ai-wiki/mcp`다.
새로고침·직접 접속·뒤로 가기는 해시와 위키 절을 동기화한다.
알 수 없는 위키 절은 개요로 복구한다.

위키는 React가 HTML로 렌더링하며 탐색과 article을 구분한다.
선택된 절은 aria-current로 알리고 절 변경 시 제목으로 포커스를 옮긴다.
태그와 링크는 키보드로 조작할 수 있고 모바일 화면에서는 표·카드와 탐색이 화면 폭에 맞는다.

## 완료 확인

주소 파싱 테스트와 기존 거래·도우미 테스트를 실행하고 타입 검사·린트·빌드를 확인한다.
브라우저에서 상단 링크와 기능 태그, 직접 주소 접속, 뒤로 가기,
위키 절 전환과 입력 도우미 복귀를 확인한다.
위키 열기 때문에 거래를 저장·수정하거나 외부 AI를 호출하면 안 된다.
