# Account Book (가계부)

수입과 지출을 기록하고 관리하기 위한 가계부 프로젝트입니다.

## 현재 상태

프로젝트 초기 단계이며, 아직 애플리케이션 소스 코드와 실행 환경이 구성되지 않았습니다.

## 프로젝트 구성

```text
account_book/
├── README.md
└── docs/
    └── agent-account-book-design.md
```

## 설계 문서

[AI 에이전트 가계부 설계 초안](docs/agent-account-book-design.md)에서 사용 형태, 서버와 에이전트의 역할, Docker Compose 구성과 환경변수 관리 계획을 확인할 수 있습니다.

## 개발 및 실행 계획

기술 스택, 의존성 설치 방법, 실행 명령은 구현이 진행되면 이 문서에 추가합니다.
현재 실행할 수 있는 애플리케이션은 없습니다.

## 문서 업데이트

개발이 진행되면 다음 내용을 업데이트합니다.

- 구현된 기능과 사용 방법
- 사용 기술 및 필요한 개발 환경
- 설치 및 실행 방법
- 테스트 방법
- 데이터 저장 방식

## 라이선스

아직 지정되지 않았습니다.
